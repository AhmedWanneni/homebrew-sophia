# Homebrew Tap for DaVinci Notes (Sophia)

Official Homebrew Cask tap for [Sophia (DaVinci Notes)](https://sophia-notes.pages.dev).

## Installation

```bash
brew tap AhmedWanneni/sophia
brew install --cask sophia
```

Or in a single command:

```bash
brew install --cask AhmedWanneni/sophia/sophia
```
